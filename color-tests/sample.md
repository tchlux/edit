# Editing Notes

Plain prose should not color words like for, class, or return as code.

- Keep movement predictable.
- Use `C-s` to search.

> Quoted text keeps its marker visible.

See [the readme](../readme.md) or https://example.com/edit for details.

**Bold markers** and _emphasis markers_ are intentionally lightweight.

```c
int main(void) {
  return 0;
}
```
