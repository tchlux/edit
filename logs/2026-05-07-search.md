# Search Milestone

Date: 2026-05-07

Implemented regex-backed forward search:

- Documented cursor positions as byte offsets between bytes.
- Added `buffer_search` using the local regex engine.
- Added batch `--search line:col regex file`, which prints match ranges as
  `line:col..line:col`.
- Added minimal interactive `C-s` search with status-line prompt and feedback.
- Extended render-key tests for `C-s` and Enter.
- Added regressions for start, middle, end-position, no-match, and interactive
  search behavior.
