# Document Highlighting

- Added path-aware default highlighting for `.md`, `.markdown`, and `.txt`
  files so prose no longer receives code keyword colors.
- Added Markdown colors for headings, links, URLs, lists, blockquotes, inline
  code, fenced code blocks, emphasis markers, and TODO-style labels.
- Added plain-text colors for URLs, list markers, quote markers, and
  TODO/FIXME/NOTE/WARN labels.
- Added `color-tests/sample.md` and `color-tests/sample.txt`, plus render-color
  regression coverage for document files.
